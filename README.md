# KENZO Telegram Bot

Готовый стартовый Telegram-бот комплекса KENZO.

## Уже работает
- /start
- красивое главное меню
- Забронировать
- Цены
- Наши услуги
- Контакты
- карточки услуг
- заявка на бронирование

## Запуск через Railway
1. Загрузите файлы в GitHub.
2. Railway → New Project → Deploy from GitHub Repo.
3. Выберите репозиторий.
4. Variables → добавьте `BOT_TOKEN` = токен от @BotFather.
5. Deploy.

## Что потом заменим
Телефон, Telegram, адрес и реальные цены. Следующим этапом можно добавить настоящий календарь, выбор даты/времени, базу бронирований и уведомление администратора.
